API 用法

  • 随机一张（按设备自动横/竖）：/pic
  • 指定方向（重定向到图片）：/pic?img=h 横图 · /pic?img=v 竖图 · /pic?img=a 任意
  • JSON 模式：/pic?json=h / /pic?json=v / /pic?json=a → 返回 {theme, folder, file, url}
  • 别名：/random 与 /pic 完全一致；在网页里直接 <img src="https://本站域名/pic"> 即可当随机壁纸源

它是怎么长大的

  • 爬虫 crawler/crawl.py：抓取 Picsum 与 Bing 每日壁纸 → 转 WebP → 按宽高比分横/竖、按平均亮度分深/浅 → SHA-256 + 感知哈希双重去重 → 自动编号并更新 count.json
  • GitHub Actions 每周一自动跑一次爬虫并提交新图，也可以手动触发（workflow: Crawl new images）
  • 自定义图源：在 crawler/sources.txt 里一行一个填入页面链接，或在 Actions 的 Crawl from URL 里直接粘贴链接，爬虫会自动提取页面图片并跟进同站详情页入库
  • 新图提交后 Cloudflare Pages 自动重新部署，域名不变
